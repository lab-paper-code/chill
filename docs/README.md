# CHILL 문서

요구사항은 명세에서, 구현 사실은 현재 소스에서 확인한다.

| 디렉터리 | 소유 내용 |
|---|---|
| [intent](intent/README.md) | 연구 목표와 사용자 결정 |
| [spec](spec/README.md) | 시스템 계약과 평가 표 |
| [design](design/README.md) | 구현 구조와 도메인별 소유 경계 |
| [adr](adr/README.md) | 유지하는 설계 결정과 근거 |
| [operations](operations/ops-agent-guide.md) | 운영 절차와 안전 경계 |

## 유지 규칙

- 같은 사실은 정본 한 곳에 두고 상대 링크로 연결한다.
- 요구사항과 명시적으로 보류한 사용자 의도를 구현 완료와 구분한다.
- 구현 설명은 현재 소스로 검증한다. 과거 실험은 당시 증거의 의미를 유지한다.
- 완료된 계획, 인수인계와 실행 기록은 Git 이력에 둔다.
- 문서에서 코드 식별자, 단위, null과 영의 차이, 불변 증거의 의미를 보존한다.
