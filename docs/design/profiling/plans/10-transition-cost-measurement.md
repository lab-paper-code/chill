## 결과 요약 — completed; estimator live gate remains open
- 결정: 한 `PowerModeTransitionCost`가 exact device/model/state pair의 양방향 측정과 off-target observer Job(동시에 최대 1개), immutable raw/finalized/terminal evidence를 소유한다. controller는 준비·순서·검증·compact status만, Node actuator는 apply/독립 read-back만 소유한다. 과거 `NodeActuation` CRD는 removed @`f4b0b685`; 현재 [Node label/generation contract](../../platform/node-agent.md#3-노드-전력모드-node-label과-generation)을 따른다.
- estimator: `tau = fresh Ready completedAt - apply startedAt`; `costWindowEndedAt = completedAt + settlingSeconds`; `wallJoules = integral(P(t), startedAt..costWindowEndedAt)`; signed `eta = wallJoules - P_idle(target) * costWindowSeconds`(clamp 없음). Serving의 `target-baseline-delta` projection은 transition energy를 `P_target * tau + eta`로 계산해 post-Ready baseline을 중복 계상하지 않는다.
- 경계: observer Ready 후 apply 시작, independent target read-back 후 frozen fresh workload Ready/process witness가 끝을 정한다. pre-existing Ready·configured delay·post-hoc power 값으로 `completedAt`을 정하지 않는다. power sample은 HTTP receipt time/request latency이며 Shelly source timestamp가 아니다. apply/target/fresh Ready의 last-absent→first-present 세 bracket 중 최대 폭을 ceil(ms)해 measured uncertainty로 쓴다. frozen ceiling/poll interval은 실측값이 아니다.
- protocol: preparation은 exact Node UID/class/model/path, two modes/actuator policies, meter/placement, workload/readiness/survival, direction order/count/attempt bounds, target baselines를 동결한다. baseline source는 namespace 안에서 current-generation Complete exact-state `ModelLoadedIdleBaseline`을 각 mode별 정확히 1개 요구하며 0개/복수는 실패다. CPU quota는 child Run의 whole-core execution-protocol 조건이지 state-pair 축·cross-mode equality 조건이 아니다.
- raw는 source/target read-back, power samples/failures+receipts, pre/post Ready process/restart facts와 세 marker bracket을 보존한다. receipt는 힌트로만 사용하고 controller가 strict load/derive하여 raw-free finalized observation과 two-row aggregate/reference를 쓴다. process가 유지되면 `servingSurvived=true`, 관측된 restart는 유효한 false, 증거 누락은 insufficient다. synthetic inference·automatic recovery는 없다.
