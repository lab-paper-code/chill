# Path-aware SLO: Problem Statement

## 문제

CHILL은 주어진 환경에서 추론 요청의 E2E elapsed time을 인지하고, 직접 제어할 수 있는 연산장치·Worker 배치로 대응해야 한다. 현재는 비연산 경로의 지연을 배치 판단에 어떻게 반영할지, SLO를 만족하기 어려울 때 무엇을 개선할지에 대한 정의가 부족하다.

## 관측 범위와 제어 범위

- **관측:** 전체 요청 지연과 각 구간의 지연, E2E SLO에 미치는 영향.
- **직접 제어:** 연산장치와 Worker의 배치.
- **환경 조건:** 주어진 테스트베드와 네트워크 환경. 환경 자체를 변경·최적화하는 일은 CHILL의 기본 책임 범위로 두지 않는다.

요청 경로 구현의 개선은 별도로 가능하다. 스케줄러는 비연산 지연을 관측하고, 그 조건에서 연산 측 배치를 어떻게 바꿀지 판단한다.

## 배치 판단의 목표

비연산 지연의 변화를 E2E SLO 만족 가능성 판단에 반영하고, 그 판단에 따라 연산장치·Worker 배치를 선택한다. 이 과정은 명시적인 수학적 모델 아래 매 스케줄링 Tick에 반영되어야 한다.

- **SLO 만족이 가능한 상황:** SLO를 만족하는 배치를 추구한다.
- **SLO 만족이 어려운 상황:** 현재 허용된 자원과 배치 제약 안에서 연산 측 지연을 줄여 SLO 만족에 가까워지도록 한다.

여기서 ‘최선’의 비교 기준은 현재 자원·배치 제약과 v2 알고리즘의 목적을 고려해 정의해야 한다.

## 위반 원인과 대응 한계

SLO 위반이 발생하면 지연의 구성과 연산 측 개선 가능성을 근거로 다음을 구분한다.

- 현재 배치나 연산 성능에 개선 여지가 있어 배치 변경으로 위반을 줄일 수 있는 상황.
- 비연산 경로의 병목이나 연산 자원 한계로, 현재 자원·배치 제약 안에서는 SLO 만족이 어려운 상황.

목표가 비현실적이라는 사실만으로 원인을 비연산 경로에 귀속하지 않는다. ‘연산 측에서 최선의 배치를 했다’는 판단과 ‘남은 위반은 비연산 경로 때문이다’라는 판단에는 각각의 근거가 필요하다.

## 후속 설계

TOTAL·POST의 시간 범위 구분을 바탕으로, 비연산 지연을 어떤 의미의 입력으로 받고 스케줄러의 제약·목적에 어떻게 연결할지 정의한다. 특정 보정식이나 구현 방식을 먼저 정하지 않고, 합의된 문제와 목표에서 수학적 모델과 구현을 도출한다.
